Matematyka zegara

Długa wskazówka — minuty

minuteAngle(m) = m × 6°

Bo 360° ÷ 60 minut = 6° na minutę.

Krótka wskazówka — godziny

hourAngle(h, m) = (h mod 12) × 30° + m × 0,5°

Bo 360° ÷ 12 godzin = 30° na godzinę, a 30° ÷ 60 minut = 0,5° na minutę.

W kodzie

function minuteAngle(minute) {
  return minute * 6;
}

function hourAngle(hour, minute) {
  return (hour % 12) * 30 + minute * 0.5;
}
